DEPLOYING TO GITHUB PAGES (after client approval)
───────────────────────────────────────────────────
1. Create a new GitHub repository (e.g., "sri-lakshmi-crackers")
2. Upload ALL files and folders to the repository root
3. Go to: Repository Settings → Pages
4. Under "Source" → Select "Deploy from branch: main"
5. Click Save and wait ~2 minutes
6. Your website goes live at:
   https://[your-github-username].github.io/sri-lakshmi-crackers

TO CUSTOMIZE FOR ACTUAL SELLER

  - Update PRODUCTS with actual product catalog
  - Add real product image paths to products[].images[]

  - Place image files in the images/ folder
  - Reference them in products.js as: images: ["images/filename.jpg"]
